Password Generator API

A small HTTP API that returns random passwords and passphrases. Everything is generated server-side with Python's secrets module, and nothing is stored or logged by the app.

Authentication

Every generator request needs an X-API-Key header. Requests without a valid key get a 403.

GET /generate

Random character passwords. Each one contains at least one lowercase letter, uppercase letter, digit and symbol, and avoids look-alike characters (O 0 l 1 I).

ParameterDefaultRange
length168–128
count11–50
lower, upper, digits, symbolstruetrue / false
avoid_ambiguoustruetrue / false
excludenoneup to 64 characters to leave out
curl -H "X-API-Key: YOUR_KEY" \
  "https://YOUR_DEPLOYMENT/generate?length=20"

{
  "password": "k7Qm2vX9pRw4tZs8NeBd",
  "length": 20,
  "entropy_bits": 124.7
}

GET /generate_phrase

Passphrases made of random dictionary words, optionally followed by digits.

ParameterDefaultRange
words43–10
sep-one character
casingtitlelower, title, upper, random
digits10–5
count11–50
curl -H "X-API-Key: YOUR_KEY" \
  "https://YOUR_DEPLOYMENT/generate_phrase?words=4"

{
  "password": "Anchor-Velvet-Mosaic-Tundra-7",
  "length": 29,
  "entropy_bits": 54.9
}

With count above 1, both endpoints return a JSON array of these objects. entropy_bits is an estimate of how hard the result is to guess.
